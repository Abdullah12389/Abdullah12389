# 🚀 Featured Projects

## 🍽️ Mess Management System

A management system designed for **400+ students, clerks, and administrators** to handle day-to-day university hostel operations, including meal fixing, bill management, and attendance tracking.

### Key Engineering Features

* 🏢 **Multi-tenant architecture** to maintain data isolation and privacy between hostels
* 🔔 **Firebase push notifications** handled through background jobs
* ⚡ **Queue-based notification system** to prevent background tasks from blocking critical services
* 📡 **Offline support** using React Query caching
* ✍️ **Fallback operations** allowing hostel administrators to manually manage attendance when the system is unavailable
* 🔐 **Secure token storage on Android** for persistent authentication and automatic login

> 🔒 The production system's source code cannot currently be made publicly available.

**Technologies:** `React Native` · `Laravel` · `Firebase` · `Queues` · `Multi-Tenancy` · `React Query` · `Docker`

## 💰 AI-Driven Finance Management System

A financial management platform designed to help small startups track their **cash burn over time**.

Users can define an initial balance, record credits and debits, and calculate their financial position over a selected period.

### Key Engineering Features

* ▲ Built and deployed as a **Next.js application**
* 🔐 JWT-based authentication and persistent sessions
* 📊 Financial data visualization using **Chart.js**
* 👤 Supports usage before login while preventing unnecessary stale data from being permanently stored
* 🧮 Tracks credits, debits, balances, and financial activity

**Technologies:** `Next.js` · `JWT` · `Chart.js` · `Vercel`
